# Security Policy

## Supported versions

This template does not publish versioned releases. Only the default branch (`main`) is supported; fixes land there. If you have already created a project from the template, the code in your project is yours to patch, and a fix here can serve as a reference.

## Reporting a vulnerability

Please do not open a public issue, pull request or discussion for a security problem.

Report it privately through GitHub: open this repository's **Security** tab, choose **Report a vulnerability**, and fill in the form. The link `https://github.com/volo-uti/flutter-boilerplate/security/advisories/new` goes straight to it.

Please include:

- a description of the problem and its impact
- the affected files or components, and the commit you tested
- steps to reproduce, or a proof of concept
- any suggested fix, if you have one

## What to expect

- We acknowledge your report within 7 days.
- We then confirm the problem, tell you how we plan to handle it and keep you updated until it is resolved.
- We fix confirmed problems on the default branch and publish a GitHub security advisory. We credit you in the advisory unless you prefer to stay anonymous.
- We ask that you keep the details private until the fix is published, and we will not ask you to wait indefinitely.

## Scope

In scope: the code, scripts and configuration in this repository, including the release lanes.

Out of scope: vulnerabilities in third-party dependencies (report those to the dependency's maintainers), and issues that only affect a project you created from the template after you changed it.
